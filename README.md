# Bootcamp Practice Sessions

A consolidated collection of hands-on exercises, labs, and mini-projects completed during my Data Science, Machine Learning, and AI learning journey.

This repository contains structured practice work covering core concepts in:

* Python Programming
* Data Analysis with Pandas & NumPy
* Data Visualization
* Statistics & Probability
* Machine Learning
* Deep Learning
* Natural Language Processing (NLP)
* Computer Vision
* SQL & Databases
* APIs and Model Deployment
* MLOps Fundamentals

## Purpose

The goal of this repository is to document continuous learning, practical experimentation, and implementation of concepts through coding exercises and guided labs.

Many of these exercises originated from bootcamp assignments, practice repositories, and self-study sessions. The work has been consolidated into a single repository to improve organization and provide a centralized reference for technical practice.

## Notes

* This repository primarily focuses on learning exercises and experimentation.
* Larger end-to-end projects are maintained separately in dedicated repositories.
* Some folders may contain notebooks, scripts, datasets, or small prototype applications.
